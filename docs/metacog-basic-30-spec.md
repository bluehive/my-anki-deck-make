# 依頼: metacog_deck を高校生向け・30問・通常フラッシュカード（Basic）へ作り直す

依頼元: ウカイ（Grok Bot 経由）。監視: Grok Bot。マージはユーザー承認後（rebase マージ）。

## 対象
- リポジトリ: https://github.com/bluehive/my-anki-deck-make （ローカル: なければ ~/my-project/ に `gh repo clone`）
- 変更ファイル: `generate_metacog_deck.py`, `metacog_deck.csv`, `import_to_anki.py`, `README.md`

## 仕様
1. 形式: 穴埋め（Cloze）をやめ、Anki 標準 `Basic` ノート（Front/Back）。
2. CSV: `metacog_deck.csv` の列は emacs_deck.csv と同じ `"表面","裏面","カテゴリ"`（全列クォート、UTF-8）。
3. 問数: ちょうど 30 問。下の「カード案」をそのまま採用（文言の微修正は可、意味は変えない）。
4. 文体: 高校生が読める言葉。専門用語は残す場合も必ず言い換えを添える。人名（Bandura 等）は出さない。
5. デッキ名は `02メタ認知アップ` のまま。タグ: `metacog`, プロジェクトタグ, カテゴリ。
6. `generate_metacog_deck.py`
   - `CARDS = [(表面, 裏面, カテゴリ), ...]`、`EXPECTED_TOTAL = 30`。
   - 検証: 件数=30、空欄なし、`{{c` を含まない、表面の重複なし、表面は「？」で終わる、裏面は 80 文字以内。
7. `import_to_anki.py`
   - `METACOG_EXPECTED_COUNT = 30`。
   - `add_metacog_note(front, back, category)` を `modelName: "Basic"`、fields `Front`/`Back` に変更。
   - `import_metacog_deck()` は `ensure_model_exists("Basic")`、列 `表面`/`裏面`/`カテゴリ` を読む。`--preflight --metacog-only` も通ること。
8. `README.md`: デッキ表を「02メタ認知アップ | 30 | Basic」に。注意書き「旧 Cloze 版を入れている場合は、Anki 側で 02メタ認知アップ の既存カードを手動で削除してから --metacog-only で入れ直す」を追加。自動削除はしない。
9. Python 実行は mise 経由 uv（素 pip 禁止）。

## カード案（表面 / 裏面 / カテゴリ）
1. 「メタ認知」ってなに？ / 自分の考え方や理解を、もう一人の自分が見張って、やり方を調整する力。 / 基本のことば
2. 「自己効力感」ってなに？ / 「この課題なら自分はできそう」と思える見込み（自信）。 / 基本のことば
3. 自己効力感と「自己肯定感」のちがいは？ / 自己肯定感は「自分には価値がある」という気持ち。自己効力感は課題ごとの「できそう」という自信。 / 基本のことば
4. 勉強を車にたとえると、メタ認知と自己効力感はそれぞれ何？ / メタ認知はメーター（計器）、自己効力感はガソリン（燃料）。両方そろって前に進む。 / 基本のことば
5. 自分で学びを回す「自己調整学習」の3つの要素は？ / メタ認知・学び方（学習方略）・やる気（動機づけ）。 / 基本のことば
6. メタ認知の「モニタリング」と「コントロール」とは？ / モニタリングは今どこまで分かっているかを見ること。コントロールはそれを見てやり方を変えること。 / 基本のことば
7. 自信を育てる一番確実な方法は？ / 「できた！」という小さな成功（達成経験）を積み重ねること。 / 自信の育て方
8. 自信のもとになる4つのものは？ / ①自分でできた経験 ②似た人の成功を見る ③理由のある励まし ④体や気持ちの状態。 / 自信の育て方
9. 「代理経験」とは？ / 自分に近い人が成功したやり方を見て「自分にもできそう」と思うこと。 / 自信の育て方
10. 効き目のある励まし方の例は？ / 「昨日のやり方なら今日も解ける」のように、理由のある励まし。 / 自信の育て方
11. テスト前に緊張したり疲れたりしたら、どう考える？ / 「能力がない」と思わず、体の状態として休む・整えるなどで対処する。 / 自信の育て方
12. 課題はどのくらいの大きさに分けるといい？ / 今の自分が8割（80%）くらいできる大きさ。 / 自信の育て方
13. 失敗したとき、まず何をする？ / 「自分はダメだ」とまとめず、次に変えることを1つだけ決める。 / 失敗したとき
14. 失敗の原因を分ける3つのラベルは？ / 知識不足・手順ミス・状態（体調や環境）。 / 失敗したとき
15. 原因が「知識不足」のときの対処は？ / 暗記カードを1枚足して、見る回数を増やす。 / 失敗したとき
16. 原因が「手順ミス」のときの対処は？ / 解き方の型（チェックリスト）を1枚作る。 / 失敗したとき
17. 原因が「状態」のときの対処は？ / 内容は変えず、勉強する時間帯や場所を変える。 / 失敗したとき
18. すらすら読めただけで「分かった」と思いこむことを何という？ / 流暢さの錯覚（分かったつもり）。 / 分かったつもり対策
19. 「閉じて書く」（検索練習）とは？ / 教科書やノートを閉じて、何も見ずに思い出して書くこと。 / 分かったつもり対策
20. 答える前の自信はどう記録する？ / 答える直前に、0〜3の4段階でつける。 / 分かったつもり対策
21. いちばん直すべきミスはどれ？ / 自信3（自信満々）なのに間違えた問題。 / 分かったつもり対策
22. 勉強の前に自分にする3つの質問は？ / 今日のゴールは1つ？ どこでつまずきそう？ 何を使う？ / 自分への質問
23. 勉強の途中で自分にする2つの質問は？ / 今どこでつまずいている？ 別のやり方はある？ / 自分への質問
24. 勉強の後に自分にする2つの質問は？ / 何がうまくいった？ 次に1つだけ変えるならどこ？ / 自分への質問
25. 「自己説明」とは？ / 「なぜそうなるか」「知っている何とつながるか」を声に出して説明すること。 / 説明して覚える
26. 「教えるつもり学習」のやり方は？ / 白紙に中学生向けの説明を書く。書けずに止まった所が理解の穴。 / 説明して覚える
27. 「精緻的質疑」とは？ / 書いてあることに「なぜ？」と自分で問いかけ、理由を言葉にすること。 / 説明して覚える
28. 単語アプリ（Ankiなど）で新しいカードは1日何枚まで？成功の基準は？ / 1日5〜20枚まで。正答率ではなく、予定の枚数を終えられたら成功。 / 毎日の実践
29. 数学で解けないとき、どうする？ / 公式・方針・計算のどこで止まったかを見つけ、「式を立てる」などの小さな一歩も成功とみなす。 / 毎日の実践
30. 明日からできる一番小さなアクションは？ / 勉強の最後の5分で「閉じて書く＋自信採点」をし、自信満々で間違えた所を1つ見つける。 / 毎日の実践

## 手順

4. 最後に PR URL とテスト・preflight の結果を出力。
