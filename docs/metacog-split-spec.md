# メタ認知デッキ カード分割仕様（Issue #14）

対象: `metacog_deck.csv`（列: 表面, 裏面, カテゴリ / Basic）、Anki デッキ「02メタ認知アップ」。
原則: **1枚 = 1つの問い = 1つの採点対象**。ただし意味のあるチャンクは分割しない。

## 方針

- 分割する: 下表の5枚（複数の独立した採点対象を含む）。
- 分割しない（チャンクとして維持）: 「自己調整学習の3つの要素」「失敗の原因を分ける3つのラベル」「自信のもとになる4つのもの」。
- それ以外の25枚は変更しない。
- 各元カードの **1枚目（★）は元ノートをその場で書き換える**（noteId と復習履歴を保持）。残りは新規ノートとして追加する。
- CSV 上では、分割後のカードは元カードの位置に順番どおり並べる（★が先頭）。

### 枚数

- 分割前: 30枚 → 分割後: **38枚**（+8: 3+1+2+1+1）
- カテゴリ別: 基本のことば 6→7 / 自信の育て方 6 / 失敗したとき 5 / 分かったつもり対策 4 / 自分への質問 3 / 説明して覚える 3→4 / 毎日の実践 3→9

### 重複・冗長性メモ

- 3b は既存「答える前の自信はどう記録する？」、3c は既存「いちばん直すべきミスはどれ？」と内容が近い。ただし既存カードは **知識**（定義）、3b/3c は **場面→行動**（最後の5分の手順）を問うので、Issue #14 の「知識カードと場面別行動カードの併用」方針に沿って残す。
- 1d は Issue #14 改善案の「3分経過」行動カードを採用した新規の行動カード。

## 実装ルール

1. `generate_metacog_deck.py` の `CARDS` を上表どおりに更新し、`EXPECTED_TOTAL = 38`。docstring の「30問」も更新。`python generate_metacog_deck.py` で `metacog_deck.csv` を再生成（手書き編集しない）。
2. `import_to_anki.py` の `METACOG_EXPECTED_COUNT = 38`。既存のインポート処理（`addNote`）の挙動は変えない。
3. 分割の対応表は機械可読な形で1か所に持つ（例: `data/metacog_split/mapping.json` か Python 定数）。各エントリ: 元の表面・元の裏面・新カード（表面/裏面/カテゴリ）の配列、先頭が in-place 更新対象。
4. Anki 移行は **別スクリプト** `scripts/metacog_split_migrate.py`:
   - **既定は dry-run**。`--apply` を付けたときだけ AnkiConnect に書き込む。
   - デッキ「02メタ認知アップ」内で元の表面に完全一致するノートを `findNotes`/`notesInfo` で探し、**ちょうど1件**でなければその元カードはスキップして警告（0件・複数件どちらも書き込まない）。
   - 1件見つかったら `updateNoteFields`（noteId 指定）で ★ 新カードの Front/Back に書き換える。ノート削除・再作成はしない（復習履歴を保持）。
   - 追加カード（★以外）は `addNote`。表面が既にデッキ内に存在する場合は追加しない（冪等: 2回実行しても重複しない）。タグは既存と同じ `metacog`, プロジェクトタグ, カテゴリ。
   - `deleteNotes` は使わない。`import_to_anki.py --metacog-only` の再実行は案内しない。
   - dry-run では「更新予定 noteId・旧→新」「追加予定」「スキップ理由」を表示。
5. テスト `tests/test_metacog_split.py`（pytest）:
   - CSV が 38 行・列が表面/裏面/カテゴリ・表面重複なし・裏面空なし・`BACK_MAX_LEN` 以内。
   - 分割した元5枚の表面が CSV に残っていない（★で書き換え済み）。チャンク3枚が原文のまま残っている。
   - generator の出力と CSV が一致。`METACOG_EXPECTED_COUNT == EXPECTED_TOTAL == 38`。
   - 移行スクリプト: AnkiConnect の `invoke` をモックし、dry-run では書き込み系アクション（updateNoteFields/addNote/deleteNotes）が呼ばれないこと、`--apply` では update 5件・add 8件・delete 0件、既に移行済みの状態では add 0件、元ノートが複数件のときスキップすること。
6. Python は mise + uv のみ（`uv run --with pytest pytest` 等）。pip は使わない。
7. 実 Anki には一切触れない（`--apply` 実行禁止、`import_to_anki.py` 実行禁止）。
