# iPhone縦画面向け数学カード

2026-10-13、起動中のAnkiConnectから `019 高校数学・基礎解析` の100ノートを読み取り専用で書き出し、その内容を修正した。

- `data/math_mobile/baseline.json`: 実際のAnkiの修正前フィールドのSHA-256ハッシュとノートID。修正前CSV全文はローカルに保管し、公開しない。
- `data/math_mobile/mobile.csv`: 同じノートIDの修正後Text・Back Extra。
- `math_deck.csv`: 従来のText/Tag/Extra形式でも利用できる修正内容。
- 既存画像2枚の参照は保持する。画像自体は公開せず、元のAnkiのcollection.mediaを利用する。別環境への移行時はAnkiのメディア同期が必要。

加法定理などを等号・加減号で複数行にし、条件を別行へ移動した。長い解説数式も改行し、画像を画面幅へ縮める。数学カード内のみに18pxの文字サイズとスタイルを指定し、共有Clozeテンプレートは変更しない。積和公式の3枚は係数を各項へ分配した同値な式で表示する。

数式途中のdivタグ（合成公式・和積公式と解説）、数式外の共役記号、TeXの連続する閉じ波括弧をClozeの終端として誤解釈する分数を修正。桁数のガウス記号をMathJaxの床関数にし、対象を整数と明記。Ankiで追加されていた解説と画像は保持した。

## 承認後の適用

Ankiを起動し、AnkiConnectを有効にして、最初に差分確認する。

```sh
python scripts/sync_math_mobile.py
```

このPRの承認後、次で適用する。

```sh
python scripts/sync_math_mobile.py --apply
```

CSV内のノートIDが対象デッキと完全一致し、修正前のフィールドが書き出し時と一致する場合だけ更新する。変更済みのノートがあれば全件の事前確認で停止する。既に適用済みのノートはスキップする。更新するのはTextとBack Extraのみで、ノートID、カードID、タグ、学習履歴、共有テンプレートは更新しない。通信エラーで途中停止した場合は再実行できる。適用後にAnkiから同期し、iPhone側でも同期する。

既存の `--fix-mathjax` は行順で対応づけるため、本変更の適用には使用しない。Textが変わるため通常のCSV再インポートは重複カードを作る可能性があり、既存デッキは上記スクリプトを使う。

生成スクリプトはこのCSVを再生成すると変更を上書きする。本変更の正本は実際のAnki書き出しと修正CSVであり、再生成時はこの表示修正を引き継ぐこと。

## 検証

- 100ノートのID集合、タグ、Cloze番号c1を保持。
- 更新前照合に生データの代わりにSHA-256を使用し、書き出し後の変更を検出。
- MathJax 3のTeX/SVGで表面・裏面計200表示を検査し、数式エラー0件。
- 320px画面、左右16px余白、本文18pxを想定。さらに数式単体は20px相当でも288px以下。
- Chromiumで320 / 375 / 390 / 430px幅の全200表示を確認し、カード領域の横はみ出し0件。画像の読み込み完了後に確認。
- AnkiConnectの更新スクリプトは差分確認のみを実行。実デッキへの変更は承認後。
- 表面の穴埋めと裏面の答えを再現したブラウザ検証。実際のAnkiMobileの描画・文字サイズ設定については適用・同期後に確認が必要。
